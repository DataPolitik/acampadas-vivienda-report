# acampadas-vivienda-report

Source of the GitHub Pages site for the report *Housing camps on Telegram, Spain,
September–October 2026*.

- `index.md` — landing page
- `acampadas_vivienda_technical_report.md` — technical report
- `community_analysis.md` — community analysis
- `external_review.md` — tagging rule and outcome
- `external_review_log.csv` — evidence and decision per reviewed channel
- `figures/` — the five figures used in the reports
- `followup.md` — overview of the follow-up (6 October to the 11 November strike)
- `followup_block1.md`, `followup_block2.md`, `followup_block3.md` — the follow-up's block reports
- `followup_review_log.csv` — evidence and decision per reviewed channel, follow-up
- `figures/followup/` — the follow-up's figures
- `figures/brand/` — the DataPolitik and Heurística logos

The site is built by GitHub Pages' default Jekyll, with no custom theme. To publish:
repository **Settings → Pages → Deploy from a branch → `main` / root**.

The reports were produced with tgmon, a Telegram monitoring tool. The data
files and scripts they mention are not part of this repository.
